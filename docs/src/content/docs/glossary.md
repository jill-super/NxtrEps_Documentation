---
title: Glossary
description: EPS, CEPS/REPS, LoA/LoSAS, ASIL and roadmap prefixes.
---

| Term | Meaning |
|---|---|
| EPS | Electric Power Steering |
| CEPS | Column-drive EPS (assist at the column; incl. low/high-output variants) |
| REPS | Rack-drive EPS (assist at the rack; ratio + ball-screw design matter) |
| LoA | Loss of Assist — classified per `supporting material/` taxonomy (sensor / current / ECU / inverter redundancy) |
| LoSAS | Loss of Steering Assist Subsystem — companion taxonomy |
| ASIL | Automotive Safety Integrity Level (ISO 26262); decomposition discussed in SE02 |
| FDD | Fault Detection & Diagnostics (modeled FDD + test plan is a typical TRM deliverable) |
| NVH | Noise, Vibration, Harshness (skew, isolators, lash, friction) |
| T-bar | Torsion bar (torque-sensor element; Gen 4 ground vs. Gen 5 non-ground) |
| PV / PPAP / SOP | Production Validation / Production Part Approval Process / Start of Production |
| FTQ / IPTV / CPV | First-Time Quality / Incidents Per Thousand Vehicles / Cost Per Vehicle |
| SE / CCM / RCM / FE / ES | Systems-Electronics / Core Mechanical / Rack-CEPS Mechanical / Front-End sensing / Electrical Systems (TRM prefixes) |
| TRM | Technology Roadmap item number (`TRM-002…TRM-204`) |
| SGMW / K2xx / C1xx / PSA / FCA | Programs/customers referenced across decks |

See also [Abbreviations](./../reference/abbreviations/) for program-specific shorthand found in slides.
