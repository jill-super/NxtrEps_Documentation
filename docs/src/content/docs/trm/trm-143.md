## Standard one-pager structure

- **Description** — what the technology is and where it applies.
- **Motivation (score)** — customer pull / competition gap (see Roadmap scoring).
- **Deliverables** — modeled FDD / test plan / build success criteria.
- **Timing** — program milestones (see dates in deck).
- **Status / Challenges / Next steps** — latest update block on slide 2.
