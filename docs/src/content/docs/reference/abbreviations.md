---
title: Abbreviations
description: Shorthand found across slides and filenames.
---

| Short | Meaning |
|---|---|
| SOP / PPAP / PV / IVER | Start of Production / Part Approval / Production Validation / Initial Verification |
| FDD / LoA / LoSAS | Fault Detection & Diagnostics / Loss of Assist / Loss of Steering Assist Subsystem |
| ASIL | Automotive Safety Integrity Level |
| CEPS / REPS / HRLOEPS | Column EPS / Rack EPS / High-Risk Low-Output EPS |
| SPM / IPM / PMSynRM | Surface / Interior Permanent Magnet / PM-assisted Synchronous Reluctance Machine |
| SINCOS / GT | Sine-cosine sensor / Giant-magnetoresistance-type sensor family |
| T&P / T-bar | Torque + Position / Torsion bar |
| FET / MOSFET | Field-effect transistor (inverter failure analysis in TRM-130) |
| TC / wTC | Temperature compensation / with temperature compensation |
| V1/V2/V3, rev 1, 03JN15… | Deck revision or date stamp — newest revision governs |
| C1xx / K2xx / CD6 / EA4 / PSA / FCA / SGMW / BMW | Programs and customers |

Filename dates use `DDMMMYY` (`19MR14` = 19 Mar 2014, `02SE15` = 2 Sept 2015).
When decks conflict, prefer the latest date + the released drawing/workbook over slides.
