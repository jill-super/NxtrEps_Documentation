This repository preserves the working documents behind the **EPS Technology Roadmap to 11MY16**:
about **120 source files** — mostly `.pptx` one-pagers and deep-dives, plus `.xlsx` models,
`.pdf` drawings and timing, and one `.png`.

## The three layers

1. **Master roadmap** — `Technology Roadmap 11MY16.xlsx` (25 sheets): scoring
   (cost / mass / packaging / performance), timing, applicability. Start at
   [Roadmap](./roadmap/).
2. **One-pagers (TRM-002…TRM-204)** — one technology per folder with the same anatomy:
   Description · Motivation (score) · Deliverables · Timing · Status / Challenges / Next steps.
   Start at [TRM index](./trm/).
3. **Deep-dives + context** — loose decks (motor noise, REPS ratio, sensorless…),
   subsystem studies (digital position, LO CEPS, M.E objectives) and leadership/customer decks.
   Start at [One-pagers by topic](./one-pagers/) and [Supporting material](./supporting-material/).

:::note[Binaries vs. docs]
Originals are PowerPoint/Excel/PDF binaries and are **not** rewritten.
The `docs/` site is a Markdown/MDX mirror: title, key points, slide-text preview,
and a **Sources** table with the exact filename + size for traceability.
:::

## Domains covered

Manufacturing · Mechanical · Motor control · NVH · Electronic · Safety.
See [Glossary](./glossary/) for CEPS/REPS, LoA/LoSAS, ASIL, FDD and the SE/CCM/RCM/FE/ES prefixes.
