## Cost levers (Stage I, tangible)

<Steps>

1. **Axial sensor application** — lower rotor (two-tooth stop-teeth, enlarged diameter), assist-housing machining, sensor cover; reference CAD SG212037 (24 mm bearing).
2. **Jacket simplification** — split → press-press upper jacket, 8 pad protrusions, one-piece compression bracket, MIG instead of laser weld, press fits.
3. **Energy-absorb delete** — remove E/A straps + retainers + rake-bracket holes.
4. **Content focus** — Fiat 319, 30/56 Nm, brushless only, rake-only column; worm/coupling/zoning/friction-spec/no-paint actions.

</Steps>
